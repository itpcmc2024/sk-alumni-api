SK Alumni System V2.6.75 – Version Sync + Settings + Member History Polish

ปรับปรุงจาก V2.6.74 โดยตรง

1) Version Sync
- อัปเดต runtime version ทั้งหน้าเว็บ, query string, footer/header, module-nav และ Worker API เป็น V2.6.75
- แก้ค่าที่ค้างเป็น V2.6.73 ใน assets/module-nav.js และ src/index.js

2) Admin Settings
- ย้าย “เวลาออกจากระบบ Admin อัตโนมัติ (นาที)” มาไว้ใต้ชุด “Admin API Key ใหม่ / ยืนยัน Admin API Key ใหม่”
- การทำงานและค่าที่บันทึกยังใช้ ADMIN_SESSION_TIMEOUT_MIN เหมือนเดิม

3) Member Portal History
- ประวัติชำระสมาชิก: วันเวลา/สถานะ และเลขที่ใบเสร็จอยู่บรรทัดเดียวกันบนจอใหญ่
- ประวัติบริจาค: รูปแบบเดียวกัน
- ประวัติสิทธิประโยชน์: แสดงเลขที่อ้างอิงการใช้สิทธิ์ (USE-...) ในบรรทัดรายละเอียดเดียวกัน
- จอเล็กอนุญาตให้ตัดเป็นบรรทัดใหม่โดยไม่ทำให้การ์ดกว้างเกินหน้าจอ

หมายเหตุ: การใช้สิทธิประโยชน์ไม่ใช่รายการรับเงิน จึงไม่มีเลขที่ใบเสร็จรับเงิน ระบบแสดง “เลขที่อ้างอิงการใช้สิทธิ์” แทนเพื่อใช้อ้างอิงอย่างถูกต้อง
