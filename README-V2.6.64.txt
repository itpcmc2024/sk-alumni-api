SK Alumni System V2.6.65 – System Completion + Admin Standardization

สรุปการปรับปรุงหลัก
- Admin SSO: เข้าสู่ระบบครั้งเดียว ใช้งานต่อเนื่องทุกโมดูล และ Logout กลับหน้า Admin Login
- Footer ฝั่ง Admin ปรับแนวทางเดียวกับหน้าบ้าน พร้อมเลขเวอร์ชัน V2.6.65
- ปุ่ม Admin / Refresh / CSV / Navigator และ Typography ปรับมาตรฐานร่วมกัน
- หน้า Status: สมาชิกใช้งานแล้วเข้าสู่ “ข้อมูลสมาชิก” ได้โดยตรงด้วย short-lived signed access token
- Benefits: แนบหลักฐาน JPG/PNG/WEBP/PDF ได้ (ไม่บังคับ), ลงบัญชีรายจ่ายอัตโนมัติ, ค้นหา/เรียง/แบ่งหน้า/CSV, แก้ไข/ลบตามเงื่อนไข
- Receipt: ระบบเล่มใบเสร็จ 100 ใบ/เล่ม, เลขรูปแบบ ปีพ.ศ.+เล่ม-ลำดับ เช่น 256901-001, รายงานนำส่งเงิน, แก้หน้า ดูใบเสร็จว่าง
- Receipt allocation และการอนุมัติรายการอยู่ใน transaction เดียวกัน เพื่อลดความเสี่ยงเลขใบเสร็จถูกใช้โดยรายการที่บันทึกไม่สำเร็จ
- Remittance: ใบเสร็จที่อยู่ในรายงาน active ใช้ซ้ำไม่ได้; เมื่อยกเลิกรายงานสามารถนำกลับมาจัดทำรายงานใหม่ได้
- Media Center: รวมรูปข่าว/กิจกรรม, รูปสมาชิก, หลักฐานชำระ, หลักฐานบริจาค และหลักฐานใช้สิทธิ์ แยกตามหมวด; หลักฐานบัญชีสำคัญล็อกการลบจาก Media Center
- Settings: แยกสีปุ่ม ปิด/ลบ และแก้ public payment topics ให้โหลดรายการ active ครบ

ข้อสำคัญก่อนอนุมัติรับเงิน/บริจาคใหม่
1) เข้า Admin > ใบเสร็จรับเงิน > เล่มใบเสร็จ
2) สร้างเล่มสำหรับปี พ.ศ. ปัจจุบัน เช่น ปี 2569 เล่ม 1 = 256901-001 ถึง 256901-100
3) เมื่อครบ 100 ใบ ระบบจะปิดเล่มและบังคับให้สร้างเล่มใหม่
