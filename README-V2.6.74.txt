SK Alumni System V2.6.74 – Receipt Recovery + Admin Key + Member Receipt Reference

Changes
- Rebuilt single receipt viewer to reliably recover Admin session from the opener tab and show explicit errors instead of a blank page.
- Added changeable Admin API Key in System Settings. The changed key is stored as SHA-256 hash in app_settings and becomes authoritative.
- Added receipt numbers to member payment/donation histories. Benefit usage shows its system reference number because benefit usage is an expense and does not issue a receipt.
- Version updated to V2.6.74.
