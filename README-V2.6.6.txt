SK Alumni System V2.6.6 – Portal Profile + Benefit History

จุดปรับปรุงหลัก
1. Navigation ภายในทุกโมดูลใช้รูปแบบเดียวกัน: Desktop แสดง icon navigation, ตัดปุ่ม “กลับหน้าหลัก”; Mobile แสดงลิงก์ “🏠 หน้าแรก” ขนาดเล็กใต้ชื่อระบบ
2. Member Portal: สมาชิกแก้ไขคำนำหน้า ชื่อ นามสกุล ชื่ออาหรับ เบอร์ อีเมล และที่อยู่ได้
3. Duplicate rule: ชื่อ + นามสกุล + อีเมลตรงกับสมาชิกอื่น = ไม่อนุญาตให้บันทึก พร้อมแจ้งรหัสสมาชิกที่ซ้ำ
4. บัตรสมาชิกดิจิทัล: เปลี่ยนหัวเป็น “สมาชิก สมาคมศิษย์เก่า”, ใช้รูปสมาชิกจริง, แสดงวันเริ่มสมาชิก/หมดอายุ และพิมพ์ให้หน้าตาใกล้บัตรบนจอ
5. หลักฐานการเป็นสมาชิก: เอกสาร A4 พร้อมข้อมูลสมาชิก รูป ที่อยู่ ช่วงสมาชิก และช่องลงนาม
6. TAB Member Portal เหลือ ข้อมูลส่วนตัว / ประวัติชำระสมาชิก / ประวัติบริจาค / ประวัติสิทธิประโยชน์
7. สิทธิประโยชน์ที่ใช้ได้ย้ายเป็นกรอบย่อยใน TAB ประวัติสิทธิประโยชน์
8. Admin Benefits เพิ่มฟอร์มบันทึกการใช้สิทธิประโยชน์ของสมาชิก และ API จะสร้าง benefit_usage อัตโนมัติเมื่อบันทึกครั้งแรก

วิธีติดตั้ง
- Copy ไฟล์ทั้งหมดทับ repo sk-alumni-api
- Commit/Sync ตามปกติ
- Cloudflare Deploy
- /api/health ต้องแสดง version 2.6.6
