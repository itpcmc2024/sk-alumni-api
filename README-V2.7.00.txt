SK Alumni System V2.7.00
Mobile UX + Dynamic Home Cover + LINE Lifecycle
================================================

ฐานเวอร์ชัน
- พัฒนาต่อจาก V2.6.98 — LINE Pastel Rich Menu + Flex UX
- คง API, โครงสร้างฐานข้อมูล, ลิงก์โมดูล และฟังก์ชันเดิมที่ใช้งานได้ดี

รายการปรับปรุง
1. ประวัติบริจาคและประวัติสิทธิประโยชน์บนมือถือจัดบรรทัดใหม่ อ่านง่ายและไม่ชนยอดเงิน
2. หน้าต่างบัตรสมาชิกดิจิทัลแนวนอนย่อให้พอดีจอและมองเห็นปุ่มควบคุม
3. ปุ่มบันทึก/ยกเลิกแก้ไขข้อมูลส่วนตัวอยู่แถวเดียวกัน
4. บัญชี LINE ที่ผูกแล้วจะแสดงรหัสสมาชิกและชื่อ แทนแบบฟอร์มผูกซ้ำ
5. ปุ่มเปลี่ยนรูปสมาชิกจัดกึ่งกลาง และหน้าลงทะเบียนตัดกล่องข้อความซ้ำซ้อน
6. ช่องวันเวลาโอนทุกโมดูลไม่ล้นกรอบจอมือถือ
7. ปรับข้อความต้อนรับ LINE ตามคำที่อนุมัติ
8. หน้าแรกเปลี่ยนชื่อเมนู “สิทธิประโยชน์” เป็น “ข้อมูลของฉัน” โดยคงลิงก์เดิม
9. Admin > จัดการข่าวสาร > จัดการข้อความหน้าแรก เปลี่ยนรูปปกได้ทั้งจอใหญ่และมือถือ
10. ข่าวสาร ประกาศ และกิจกรรม แนบได้สูงสุด 8 รูปต่อรายการทุกหมวด
11. LINE แจ้งเตือนสมาชิกที่ผูกบัญชีเมื่อแจ้งชำระ/บริจาค, อนุมัติสมาชิก, ยืนยันหรือไม่อนุมัติรายการ และบันทึกการใช้สิทธิ์
12. Rich Menu ใหม่ 6 ช่อง: หน้าหลัก, เชื่อมบัญชี, ตรวจสอบสถานะ, สนับสนุนรายปี, บริจาค, โทรหาแอดมิน

ขนาดรูปปกหน้าแรก
- จอใหญ่: 1920 × 360 px
- มือถือ: 940 × 340 px
- รองรับ JPG, PNG, WEBP ระบบจัดกึ่งกลาง ตัดขอบ และบีบอัดเป็น JPG ให้ตรงขนาดอัตโนมัติ

ตั้งค่าโทรหาแอดมิน
1. เข้า Admin > ตั้งค่าระบบ > การรับเงิน
2. กรอก “เบอร์โทรแอดมินสำหรับปุ่ม LINE”
3. กดบันทึกการตั้งค่า
4. ตั้ง Rich Menu ช่องโทรเป็นข้อความ “โทรหาแอดมิน” ตามไฟล์ LINE-RICH-MENU-SETUP-V2.7.00.txt

การติดตั้ง
1. นำไฟล์ทั้งหมดวางทับโฟลเดอร์ GitHub เดิม
2. Commit และ Push หน้าเว็บขึ้น GitHub Pages
3. Deploy Worker ด้วยคำสั่ง: npx.cmd wrangler deploy
4. ไม่ต้องรัน SQL migration เพิ่มสำหรับเวอร์ชันนี้
5. อัปโหลด assets/line-rich-menu-v2.7.00.png ใน LINE OA Manager และกำหนด Action ตามคู่มือ

การทดสอบที่แนะนำหลัง Deploy
- iPhone/Android ทั้งแนวตั้งและแนวนอน: ข้อมูลสมาชิก บัตรสมาชิก ฟอร์มวันเวลา
- เปลี่ยนรูปปกเดสก์ท็อปและมือถือ แล้วรีเฟรชหน้าแรก
- เพิ่มข่าว/ประกาศ/กิจกรรมอย่างละ 8 รูป และตรวจหน้า news.html
- ใช้บัญชี LINE ที่ผูกรหัสแล้วทดสอบแจ้งชำระ บริจาค อนุมัติ และใช้สิทธิ์
- แตะ Rich Menu ครบ 6 ช่อง โดยเฉพาะ “โทรหาแอดมิน”
