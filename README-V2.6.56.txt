SK Alumni System V2.6.56 – News Media + Home Dashboard Phase 3

- Dashboard ข่าวใช้สีสัมพันธ์กับหมวด: ทั้งหมด=ม่วง, ข่าวสาร=เขียว, ประกาศ=ฟ้า, กิจกรรม=ชมพู
- กิจกรรมรองรับสูงสุด 10 รูปจริง พร้อมย่อรูปอัตโนมัติรายรูป และตรวจเพดานรวมแบบ Gallery
- เพิ่มคลังรูปในระบบในโมดูลข่าวสาร: อัปโหลด/ค้นหา/กรอง/ดู/นำไปใช้กับข่าว/ลบ
- หน้าแรก: กรอบข่าวแสดงข่าวเด่นก่อน จากนั้นข่าวล่าสุด และมี scrollbar เมื่อเกิน 3 รายการ
- หน้าแรก: จำนวนสมาชิกล่าสุดดึงข้อมูลจริง สมาชิกทั้งหมด/สมาชิกปีนี้/สมาชิกใหม่เดือนนี้/กิจกรรมปีนี้
- HOME_QUOTE / HOME_QUOTE_BY / HOME_NEWS_TITLE เปิดให้บันทึกและอ่านผ่าน public settings ได้จริง
- อัปเดตเวอร์ชันทั้งชุดเป็น V2.6.56
- ต้อง Deploy Worker ใหม่ เพราะเพิ่ม API home summary, media library และแก้ validation gallery
