SK Alumni System V2.6.79.2.1 – LINE Member Account Linking

เพิ่มจาก V2.6.89.1:
1) เมนู LINE เปลี่ยน “สมาชิก” เป็น “ตรวจสอบสถานะ” และลิงก์ไป status.html
2) คำสั่งเดิม “สมาชิก” ยังใช้เป็น alias ของ “ตรวจสอบสถานะ” เพื่อความต่อเนื่อง
3) เพิ่มคำสั่ง “เชื่อมบัญชี” สำหรับผูก LINE User ID กับรหัสสมาชิก
4) ลิงก์เชื่อมบัญชีเป็น one-time token อายุ 15 นาที และตรวจสมาชิกด้วยรหัสสมาชิก + อีเมล/เบอร์โทรเดิม
5) สมาชิกต้องมีสถานะ active จึงเชื่อมบัญชีได้
6) หลังเชื่อมแล้ว คำสั่ง “ข้อมูลของฉัน” สร้างลิงก์ Member Portal อายุ 10 นาทีโดยไม่ต้องกรอกรหัสซ้ำ
7) ป้องกันรหัสสมาชิกเดียวเชื่อมกับ LINE active มากกว่าหนึ่งบัญชี
8) ตาราง line_link_tokens ถูกสร้างอัตโนมัติเมื่อใช้งานครั้งแรก ไม่ต้องรัน SQL แยก
