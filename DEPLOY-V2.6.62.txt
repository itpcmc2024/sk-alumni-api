SK Alumni System V2.6.62 – Full Package READY
================================================

แพ็กเกจนี้แก้จุดสำคัญ:
- Frontend version ถูกบังคับเป็น 2.6.62 จริง (module-nav.js / site.js / query version)
- admin.html ใช้ Admin Key ชุดเดียวกับโมดูล Admin อื่น
- เพิ่ม fallback ตรวจสิทธิ์สำหรับหน้า "จัดการสมาชิก"
- localStorage/sessionStorage รองรับชื่อ key ทั้ง 3 แบบ:
  sk_alumni_admin_key / SK_ALUMNI_ADMIN_KEY / adminKey
- Worker src/index.js รวมอยู่ในแพ็กเกจเดียวกัน

วิธีนำขึ้นระบบ
1. แตก ZIP
2. เปิดโฟลเดอร์ sk-alumni-api ของคุณใน VS Code
3. นำ "ไฟล์ข้างใน" โฟลเดอร์ SK-Alumni-System-V2.6.62-Full-Package-READY
   ไปแทนไฟล์ในโฟลเดอร์ sk-alumni-api เดิม
   สำคัญ: อย่านำทั้งโฟลเดอร์ไปซ้อนเป็น sk-alumni-api/sk-alumni-api
4. Terminal:
   git status
   git add -A
   git commit -m "SK Alumni System V2.6.62 Full Package"
   git push origin main
5. Deploy Worker:
   npx wrangler deploy
6. ตรวจสอบก่อนเปิดเว็บ:
   grep -R "const V='2.6.62'" assets/module-nav.js
   grep -R "VERSION:'V2.6.62'" assets/site.js
7. เปิดหน้า:
   admin.html?v=2.6.62

ถ้าเคยจำ Admin Key เก่าไว้และยังล็อกอินไม่ได้:
- กด "ออกจากระบบ" จากโมดูล Admin ที่เข้าได้
- เปิด admin.html?v=2.6.62
- กรอก Admin API Key ใหม่ 1 ครั้ง
หลังจากนั้น key จะถูกแชร์ให้โมดูล Admin อื่น

หมายเหตุ:
อย่าใช้ไฟล์ module-nav.js จาก V2.6.61 ปะปนกับชุดนี้ เพราะไฟล์นั้นจะเปลี่ยน URL กลับเป็น ?v=2.6.61
