SK Alumni System V2.6.96 – LINE Sticker + Fast Send + Print Footer Polish

ต่อยอดจาก V2.6.95.1 – Admin Account Management Polish

รายการปรับปรุง
1. LINE สมาชิก
   - รับ Webhook ข้อความชนิด sticker เข้าห้องสนทนา Admin แล้ว
   - แสดงข้อความสติ๊กเกอร์ พร้อม Package ID / Sticker ID ที่ LINE ส่งมา
   - รองรับข้อความประกอบของ Message Sticker เมื่อ LINE ส่งข้อมูล text มาให้
   - ไม่พยายามดาวน์โหลดภาพสติ๊กเกอร์ เนื่องจาก LINE Messaging API ไม่เปิดให้ดึงไฟล์ภาพสติ๊กเกอร์ที่ผู้ใช้ส่ง

2. ลดเวลาส่งข้อความจาก Admin ไป LINE สมาชิก
   - ข้อความตัวอักษรส่งไป LINE ก่อนงานบันทึกประวัติฐานข้อมูล
   - งานบันทึกข้อความและสถานะอ่านทำต่อแบบ background ด้วยการเชื่อมต่อฐานข้อมูลแยก
   - หน้า Admin แสดงข้อความที่ส่งสำเร็จทันที โดยไม่รอโหลดห้องสนทนาทั้งชุดซ้ำ
   - รูปและไฟล์ยังคงบันทึกก่อนส่ง เพื่อให้ URL สื่อพร้อมใช้งานเมื่อ LINE เรียกไฟล์

3. แบบพิมพ์
   - ใบเสร็จรับเงิน, ใบเสร็จหลายใบ และใบนำส่งเงิน แสดง
     ผู้พิมพ์: ... · พิมพ์ครั้งที่ ...
     ในบรรทัดเดียวกันที่มุมซ้ายล่าง
   - Copyright / Version คงอยู่มุมขวาล่าง ขนาดเล็กและสีอ่อน

4. Version
   - อัปเดตหน้าเว็บ, Worker API และ cache query เป็น V2.6.96

ไม่ต้องรัน SQL migration เพิ่ม

Windows deploy
git add -A
git commit -m "SK Alumni System V2.6.96 LINE Sticker Fast Send Print Footer Polish"
git push origin main
npx.cmd wrangler deploy

ทดสอบหลัง Deploy
1. สมาชิกส่งสติ๊กเกอร์ LINE แล้วตรวจว่าปรากฏใน Admin > LINE สมาชิก
2. Admin ส่งข้อความตัวอักษร แล้วตรวจว่าหน้าจอขึ้น “ส่งแล้ว” และ LINE ได้รับรวดเร็ว
3. ทดสอบส่งรูปและไฟล์เดิม
4. พิมพ์ใบเสร็จเดี่ยว, หลายใบ และใบนำส่งเงิน เพื่อตรวจบรรทัดผู้พิมพ์
