SK Alumni System V2.7.03 — Complete News, LINE Identity and Mobile Member Table Fix

รายการที่แก้ไขครบในรุ่นนี้

1. ข่าวสารและกิจกรรม
   - ข่าวที่มีหลายรูปใช้ปุ่ม “รูปก่อนหน้า / รูปถัดไป” และตัวนับรูป
   - ยกเลิกการใช้แถบรูปแบบเลื่อนเป็นวิธีหลัก ทั้งหน้าข่าวและป๊อปอัปหน้าแรก
   - แก้ไขข่าวเดิมแล้วเพิ่มรูปได้ โดยคงรูปเก่าไว้จนกว่าจะเลือก “ลบรูปเดิมทั้งหมด”
   - รองรับรูปเก่าที่เคยมีขนาดใหญ่ เพื่อไม่ให้การเพิ่มรูปใหม่ถูกปฏิเสธโดยไม่จำเป็น
   - จำกัดไม่เกิน 8 รูปต่อรายการ

2. ความเร็วและการตอบกลับตอนบันทึก
   - ข่าวสาร การตั้งค่าระบบ และการแก้ไขสมาชิก แสดงสถานะ “กำลังบันทึก” ทันที
   - แสดงผลสำเร็จทันทีเมื่อ Worker ตอบรับ และรีเฟรชข้อมูลรายการแบบเบื้องหลัง

3. ติดต่อแอดมินผ่าน LINE
   - คำสั่ง Rich Menu “ติดต่อแอดมิน” หรือ “โทรหาแอดมิน” จะอ่านข้อความเดียวกัน
   - หากเปิดการโทรและตั้งเบอร์ไว้: ส่ง Flex Message พร้อมปุ่ม “โทรเลย” (tel:)
   - หากปิด: ส่งข้อความแจ้งให้รอแอดมินส่งคำขอการโทรผ่าน LINE
   - ตั้งค่าที่ Admin > ตั้งค่าระบบ > เบอร์โทรแอดมิน และติ๊ก “เปิดให้สมาชิกกดโทรจากเบอร์นี้”

4. ข้อมูล LINE สมาชิก
   - แยก LINE ID ออกจาก LINE User ID อย่างชัดเจน
   - ตารางสมาชิก: คอลัมน์รหัสแสดง LINE ID หรือ “ยังไม่เชื่อม LINE”; คอลัมน์ชื่อ-สกุลแสดง LINE User ID เมื่อเชื่อมแล้ว
   - หน้ารายละเอียดและหน้าแก้ไขแสดงสองค่าแยกกัน
   - หน้าแก้ไขมีตัวเลือก “ยกเลิกการเชื่อมบัญชี LINE” ซึ่งจะตัดการเชื่อมอย่างปลอดภัย
   - กรณีข้อมูลเก่าที่เก็บ U... ไว้ในช่องเดิม ระบบจะแสดงเป็น LINE User ID ให้ถูกต้อง

5. ตารางสมาชิกบนมือถือ
   - ใช้ตารางแนวนอนที่เลื่อนด้วยแถบเลื่อน (ไม่บีบข้อความให้ตกบรรทัด)
   - คอลัมน์จัดการคงปุ่มขนาดปกติ เรียงในบรรทัดเดียว ไม่ยืดเต็มความกว้าง
   - จอขนาดกลางลดช่องว่างและขนาดตัวอักษรโดยไม่ตัดข้อมูลสำคัญ

การติดตั้ง

1) แตก ZIP ทับโฟลเดอร์โปรเจกต์เดิม
2) git add -A
3) git commit -m "SK Alumni System V2.7.03 complete fixes"
4) git push origin main
5) npx wrangler deploy

ทดสอบหลังติดตั้ง

- ข่าวที่มีรูปเดิม 2-3 รูป: เพิ่มรูปใหม่ 1 รูปโดยไม่ติ๊กลบรูปเดิม
- Rich Menu ช่องติดต่อแอดมินต้องตั้ง Action เป็น “ส่งข้อความ” ค่า: ติดต่อแอดมิน
- เปิด/ปิดการโทรในหน้าตั้งค่าระบบ แล้วทดสอบส่งข้อความ “ติดต่อแอดมิน” จาก LINE
- เปิด Admin > จัดการสมาชิก เพื่อตรวจ LINE ID และ LINE User ID ของ 69-SK0001
- เปิดตารางสมาชิกบนโทรศัพท์และเลื่อนแนวนอนเพื่อดูทุกคอลัมน์
