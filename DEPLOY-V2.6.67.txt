SK Alumni System V2.6.68 – Deploy

1) แตกไฟล์แล้วนำไฟล์ทั้งหมดแทนที่ในโฟลเดอร์ sk-alumni-api
2) ที่ VS Code Terminal รัน:
   npm install
   git add -A
   git commit -m "SK Alumni System V2.6.68 Member Portal Remittance Media UX Fix"
   git push origin main
3) Deploy Worker:
   npx wrangler deploy
4) รอ GitHub Pages deploy เสร็จ แล้ว Hard Reload (Mac: Command + Shift + R)
5) ทดสอบ URL ด้วย ?v=2.6.68

จุดทดสอบสำคัญ:
- benefits.html -> login -> member.html -> ออกจากข้อมูลของฉัน ต้องกลับ benefits.html
- member.html ต้องไม่เห็นข้อความ bootstrapStatusPortal(); ที่ท้ายหน้า
- remittance.html ต้องแสดงหัวข้อรายงานชิดซ้าย, วันที่มีชื่อวัน, footer ใหม่
- admin-content.html > จัดการรูปในระบบ thumbnail ต้องเล็กลง และกดดูรายละเอียดได้
- admin-benefits.html > สิทธิประโยชน์ทั้งหมด การ์ดต้อง compact
