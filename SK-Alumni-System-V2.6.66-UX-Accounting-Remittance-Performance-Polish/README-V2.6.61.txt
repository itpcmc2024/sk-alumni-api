SK Alumni System V2.6.61 – Admin SSO + Benefits & Media Fix

- Admin Single Sign-On: ใช้ Admin API Key ครั้งเดียวและแชร์ทุกโมดูล Admin
- แก้หน้า Admin จัดการสมาชิก: ตรวจสิทธิ์แยกจากการโหลด schema และมี fallback เมื่อ address join มีปัญหา
- ปุ่ม ศูนย์จัดการระบบ / ออกจากระบบ ขนาดมาตรฐานเดียวกันบนจอใหญ่
- สิทธิประโยชน์: แก้ไข เปิด/ปิด ได้
- บันทึกการใช้สิทธิ์: ตาราง ดู/แก้ไข/ลบ (soft delete)
- มูลค่าการใช้สิทธิ์ > 0 ลงสมุดบัญชีเป็นรายจ่ายอัตโนมัติ; แก้ไข sync บัญชี; ลบเปลี่ยน ledger เป็น void
- หน้า public สิทธิประโยชน์: เฉพาะสมาชิก active และไม่หมดอายุ, กล่องข้อมูลตามแนวทางที่กำหนด, ดูข้อมูลของฉันต่อ session โดยไม่ login ซ้ำ
- Payment topics: ไม่ตัดหัวข้อที่ชื่อคล้ายกัน ทำให้แสดงหัวข้อ active จาก Admin ครบ
- จัดการรูป: เพิ่มหมวดรูปสมาชิก/หลักฐาน และคงการรวมรูปสมาชิกที่ดึงจากฐานข้อมูล
- Version runtime ทั้ง frontend/API อัปเดตเป็น V2.6.61
