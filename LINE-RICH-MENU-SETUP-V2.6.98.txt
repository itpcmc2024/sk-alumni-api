ตั้งค่าใน LINE Official Account Manager
1) เข้า https://manager.line.biz/ และเลือกบัญชีของสมาคม
2) เลือก Rich menus > Create new
3) ตั้งชื่อ: SK Alumni Member Menu V2.6.98
4) Display period: กำหนดวันเริ่มต้นเป็นวันนี้ และวันสิ้นสุดตามที่ต้องการ
5) Menu bar label: เมนูสมาชิก
6) Default display: Display
7) เลือกเทมเพลต 6 ช่อง แบบ 3 คอลัมน์ x 2 แถว
8) อัปโหลด assets/line-rich-menu-v2.6.98.png
9) ตั้ง Action ของทั้ง 6 ช่องเป็น Text แล้วกรอกตามนี้ (ต้องตรงทุกตัวอักษร)

ช่องซ้ายบน    Text: ข้อมูลของฉัน
ช่องกลางบน    Text: เชื่อมบัญชี
ช่องขวาบน     Text: บัตรสมาชิก
ช่องซ้ายล่าง   Text: ประวัติของฉัน
ช่องกลางล่าง   Text: สิทธิประโยชน์
ช่องขวาล่าง    Text: ติดต่อแอดมิน

10) Save แล้วเปิดแชท LINE OA เพื่อตรวจทั้ง 6 ช่อง

พิกัดสำหรับกรณีสร้างผ่าน Messaging API
1. x=0,    y=0,   width=834, height=843 — ข้อมูลของฉัน
2. x=834,  y=0,   width=833, height=843 — เชื่อมบัญชี
3. x=1667, y=0,   width=833, height=843 — บัตรสมาชิก
4. x=0,    y=843, width=834, height=843 — ประวัติของฉัน
5. x=834,  y=843, width=833, height=843 — สิทธิประโยชน์
6. x=1667, y=843, width=833, height=843 — ติดต่อแอดมิน

การทดสอบหลัง Deploy
- เพิ่มเพื่อนใหม่: ได้ Flex Message ต้อนรับ พร้อมปุ่มลงทะเบียน/เชื่อมบัญชี/เมนู
- พิมพ์ “เมนู”: ได้ Flex Message เมนู 6 รายการ
- ประวัติของฉัน: ได้เมนูย่อย ชำระค่าสมาชิก/บริจาค/ใช้สิทธิ์
- ข้อมูลของฉันและบัตรสมาชิก: ได้ลิงก์ส่วนตัวอายุ 10 นาที
- เชื่อมบัญชี: ได้ลิงก์ส่วนตัวอายุ 15 นาที
- ติดต่อแอดมิน: ข้อความถัดไปเข้า LINE Inbox ของ Admin ตามเดิม

หมายเหตุ
- Webhook URL และ Channel settings เดิมใช้ต่อได้ ไม่ต้องสร้าง Provider หรือ Channel ใหม่
- ไม่ต้องใช้ LIFF ในเฟสนี้ เพราะระบบมี signed Member Portal link อยู่แล้ว
- ถ้า Rich Menu เก่าแสดงทับ ให้ปิด/ลบเมนูเดิม หรือเอาการผูกเมนูรายบุคคลเดิมออกก่อน
