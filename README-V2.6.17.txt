SK Alumni System V2.6.19 – Finance UX + Receipt Polish + Admin Card Ordering

สิ่งที่ปรับในเวอร์ชันนี้
1) ชื่อระบบบน Header แบ่งเป็น 2 บรรทัดอัตโนมัติ โดยแยกก่อนคำว่า “นูรุ้ลอิสลามสัมพันธ์” และบรรทัด Nurul Islam เดิมยังคงอยู่
2) หน้า “สนับสนุนสมาคมฯ รายปี” ใช้ Public Payment Topics แบบ fail-soft ไม่ทำ DDL ในคำขอสาธารณะ และ fallback เป็นหัวข้อค่าบำรุงรายปีจาก Admin Settings เมื่อฐานข้อมูลเป็นโครงสร้างเดิม
3) Admin Center ลบการ์ด “กลับหน้าบ้าน” และเพิ่มการลากเรียงการ์ด + ปุ่มขึ้น/ลง พร้อมจำลำดับใน browser
4) Admin Settings เพิ่ม “ที่อยู่สมาคม” สำหรับแสดงบนใบเสร็จ
5) ใบเสร็จ A4 ต้นฉบับ+สำเนา: โลโก้ใหญ่ขึ้น, ใช้ที่อยู่สมาคมแทนชื่อระบบบรรทัดรอง, ตัวเลขเป็นคำอ่านภาษาไทย, ช่องคำอ่านยอดเงินมีพื้นหลัง, ลายเซ็นมีพื้นที่มากขึ้นและมีตราประทับ, มุมขวาใช้ ต้นฉบับ/สำเนา และลายน้ำกลางใบเป็น “ใบเสร็จรับเงิน”
6) จำนวนครั้งพิมพ์จะเพิ่มและบันทึก Log เฉพาะเมื่อกดปุ่ม “พิมพ์ต้นฉบับ + สำเนา” เท่านั้น (ทั้งรายใบและพิมพ์ชุด)
7) Modal ประวัติธุรกรรมเพิ่มปุ่ม “ปิด” ด้านล่างหลังปุ่มใบเสร็จ/สถานะ
8) API /api/health และ APP_VERSION เป็น 2.6.19

วิธีติดตั้ง
- แตก ZIP แล้วนำไฟล์ทั้งหมดแทน V2.6.16
- npx wrangler deploy
- ตรวจ https://sk-alumni-api.itpcmc2024.workers.dev/api/health ต้องเห็น version 2.6.19
- git add .
- git commit -m "SK Alumni System V2.6.19 - Finance UX Receipt Polish Admin Card Ordering"
- git pull --rebase origin main
- git push origin main

จุดทดสอบหลัก
A) Admin Settings: บันทึกชื่อระบบ + ที่อยู่สมาคม + ค่าบำรุง
B) index.html: ชื่อระบบ 2 บรรทัด
C) payment.html: โหลดหัวข้อและยอดได้ แม้ตาราง payment_topics เดิมยังไม่ครบ
D) admin-home.html: ลาก/เลื่อนการ์ด และรีเฟรชแล้วลำดับเดิมยังอยู่
E) receipt.html: ต้นฉบับ/สำเนา, คำอ่านยอดเงิน, ที่อยู่สมาคม, ตราประทับ
F) ก่อนกด Print จำนวนครั้งไม่เพิ่ม; หลัง Print Log เพิ่ม 1 ครั้ง
