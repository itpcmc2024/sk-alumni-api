SK Alumni System V2.6.17 – Admin Payment & Donation Control Center

สิ่งที่เพิ่มในเวอร์ชันนี้
1. Admin Transaction Control Center
   - แยก TAB ค่าบำรุง / เงินสนับสนุน-บริจาค / บัญชีรายรับจากระบบ
   - ค้นหา กรองสถานะ เรียงเก่า-ใหม่/ใหม่-เก่า และเลือกจำนวนแถว
   - ดูรายละเอียดธุรกรรมและสลิปแบบ Modal
   - อนุมัติ / ไม่อนุมัติ พร้อมหมายเหตุผู้ตรวจสอบ
2. Payment Approval
   - ป้องกันอนุมัติซ้ำ
   - เมื่ออนุมัติ: ต่ออายุสมาชิก 1 ปี + เปลี่ยนสถานะ active + ลง ledger รายรับอัตโนมัติ
3. Donation Approval
   - เพิ่ม API อนุมัติ/ไม่อนุมัติ
   - เมื่ออนุมัติ: ลง ledger รายรับเงินบริจาคอัตโนมัติ
4. Admin Settings
   - ชื่อบัญชี / ธนาคาร / เลขบัญชี / PromptPay / ค่าบำรุงรายปี
   - จัดการหัวข้อชำระและหัวข้อบริจาค เพิ่ม/แก้ไข/ปิดใช้งาน
5. Version sync
   - API / Public / Member / Admin sync เป็น V2.6.17

หมายเหตุ
- ใช้ฐานข้อมูลเดิมแบบ additive ไม่ลบข้อมูลเดิม
- V2.6.17 ถัดไป: ใบเสร็จ + เลขที่ใบเสร็จ + ระบบบัญชี/พิมพ์เอกสาร
